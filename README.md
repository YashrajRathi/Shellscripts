# Shellscripts

## Reason 
These are some alias and bashscript combination that I use to expedite my work. Best thing about aliases is that they are just a _Tab_ key away from completion.

## Use
You can add the [shortcut](https://github.com/YashrajRathi/Shellscripts/tree/main/shortcuts) scripts to your machine
Then add them as aliases in ~/.bashrc as below
`````````````````````````````````````````````
alias some_alias="path/to/some/script.sh"

`````````````````````````````````````````````
